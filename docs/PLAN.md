# AirTools 设计说明

## 定位

AirTools 是一个 Windows 托盘程序（`AirTools.exe`），自己完成全部功能：剪切板历史、晾衣架、快速命令、系统监控。PowerToys 命令面板扩展只是它的**可选入口**，不保存数据、不带后台进程。

| 功能 | 独立版 `AirTools.exe` | 命令面板扩展 |
|---|---|---|
| 快速命令 | 搜索栏按名称 / 别名运行；设置里新增、编辑、删除；独立快捷键；结束运行 | 「AirTools 快速命令」：搜索并运行、结束运行、看日志；编辑跳转到 AirTools 设置 |
| 剪切板历史 | 唯一的记录与存储；搜索、置顶、删除、清理、导入；条数 / 保留时长 / 图片内存上限可设；可暂停 | 「AirTools 剪切板」：搜索、粘贴、仅复制、置顶、删除、图片预览 |
| 粘贴、晾衣架、监控 | 全部在独立版 | 无 |
| 设置 | 全部设置都在独立版统一配置 | 只有一页：说明、“打开 AirTools 设置”按钮、关于与 GitHub 地址 |

搜索启动器刻意保持小而美：只做**快速命令**和**剪切板搜索**。文件搜索、文件索引、收藏、最近文件已移除，通用文件搜索请使用 Windows 搜索或 PowerToys 命令面板自带的功能；计算器、时间戳等同理，AirTools 不重复实现。

## 扩展如何联动

- 扩展是独立版的**客户端**：通过仅限当前用户的命名管道 `AirTools.Host.<hash>` 请求，独立版里的 `PipeServer` 是唯一的服务端。管道名由用户名与数据目录哈希得到，两端共用 `src/AirTools.Core` 里的协议。
- 扩展不读写历史文件，不传凭据或任意命令；只发送“列出 / 粘贴 / 置顶 / 运行 / 结束 / 打开设置”这类按 ID 操作的请求。
- 独立版没有运行时，扩展提示“请先运行 AirTools 独立版”，不会私自拉起任何后台。
- 回车粘贴：先写入剪切板，等命令面板关闭、原窗口重新成为前台，再粘贴一次；焦点没有回到其他应用就只复制。

## 安装扩展

设置 → 命令面板 → “安装到命令面板”。`ExtensionInstaller` 的流程：

1. 检测命令面板与“开发人员模式”；未开启时给出明确提示，不去改系统设置。
2. 取扩展包：优先用 `AirTools.exe` 同目录的 `AirTools-Extension-x64.zip`（发布压缩包自带），否则从 GitHub Releases 最新版下载。
3. 校验是 MSIX 布局（含 `AppxManifest.xml` 与 `AirTools.CommandPalette.exe`），卸载旧版本并保留应用数据，解压到 `%LOCALAPPDATA%\AirTools\Extension`，以开发模式 `Add-AppxPackage -Register` 注册，再请求命令面板重载。
4. 解压位置在数据目录而不是程序目录，所以移动或删除 AirTools 文件夹不会弄坏扩展。

没有证书、不需要管理员权限。正式发布到 Microsoft Store 或使用签名包不在当前范围内。

## 平台边界

当前只做 Windows（C# / .NET 8 / WPF + Win32，扩展为 .NET 10）。`RecentTextRack`、`SnapService` 等逻辑不依赖窗口，便于以后迁移；`NonActivatingWindow`、`PasteHelper` 封装 Windows 行为。macOS / Linux 暂不做。

## 验收清单

- 未安装 PowerToys 时，晾衣架、剪切板历史、快速命令、监控全部可用，数据无需迁移。
- 安装 / 重装 / 卸载扩展后，命令面板里能看到或看不到 AirTools；旧历史、任务、设置不受影响。
- 扩展与独立版始终只有一个剪切板监听；修改任务后扩展里立即可见。
- 在记事本、浏览器、VS Code、终端里分别点击卡片 / 回车粘贴：不误粘、不重复；焦点变化时降级为只复制。
